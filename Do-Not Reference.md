# RVNW Studios — Do-Not / Anti-Pattern Reference

Rejected directions from the rebrand process. If Claude Design (or anyone else building this) reaches for any of these, it's drifting off-brief.

## Naming
- Never use "Diagnose / Deploy / Compound" — a local competitor owns this exact wording. Locked replacement: **Map / Ship / Multiply**.
- Never reuse "Strategy" as a process-phase name — it's already one of the six named disciplines. Reusing it across two different systems on the same site reads as a naming collision, not intentional structure.

## Color
- No blue as a brand color, in any saturated form — collides with Cooper Concrete's Blueprint blue (`#2D5EF9`), a client case study that sits on this same site.
- No crimson/blood-red family reds — already claimed by Thread House Ink and Royal Peacock.
- Never use Cooper Concrete's exact values (`#2D5EF9` blue, `#FF3B30` oxide) anywhere in RVNW's own system.
- No two co-equal saturated hero colors (e.g. the earlier blue+lime direction) — one hero color, committed to, against black/white. Two vivid colors stacked together reads as generic "bold agency" template, not a considered system.
- No neon/acid lime-green as a brand color — overused in the current creative-studio market, discarded direction.

## Shape / geometry
- No soft app-icon squircle containers anywhere in the system — the logo's chamfered/cut-corner language is the shape signature for cards, inputs, tags, and containers. Rounded corners fight it there.
- **Exception, updated 2026-08-18:** buttons are now pill-shaped (fully rounded) — a deliberate reversal of the earlier "no pills anywhere" rule, chosen for a more tech-forward feel. Do not extend pill shapes past buttons — this exception is scoped to buttons only, everything else in the previous bullet still applies.
- The R mark never sits inside a container/frame — it ships bare, on transparent background, always.

## Typography
- Never set body copy in JetBrains Mono — reserved strictly for technical accents (stats, tags, meta labels, timestamps), never paragraphs.
- Don't let headings and body share a typeface with no contrast — Public Sans (headings) and Instrument Sans (body) need to read as distinct roles, not interchangeable.

## Layout
- No default hero → features → testimonials → CTA stacking without explicit justification for why that order serves this specific goal.
- No identical spacing/background rhythm section after section — full-page hero sections exist specifically to create visual separation and contrast between sections, not uniform scroll.
- No generic uniform card grids as the default component pattern.

## Copy
- No agency fluff: "unlock," "elevate," "seamless," "leverage," "cutting-edge," "game changer," "synergy," "holistic," "streamline."
- No paired synonyms ("clear and concise," "robust and scalable") — pick one word.
- No "it's not just X, it's Y" constructions.
- No generic confident-startup voice — the tone is a senior operator talking to senior operators. This site is the credibility proof for every other client pitch; it's held to the strictest version of the voice rules in the whole roster.
- No over-claiming proof for verticals without a case study behind them (currently: general SaaS/tech within the startups vertical, outside fintech specifically).

## Business model
- No references to the old productized tiers (Foundation/Framework/Momentum/Cornerstone) as the current pricing model — the site now reflects value-based, project-scoped custom proposals.
